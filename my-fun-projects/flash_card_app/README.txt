===========================================
SUMMARY
===========================================
THIS WEBAPP WILL BE FOR PERSONAL USE ONLY. ALL THE CARDS WILL USE A LOCAL DATA BASE
OF QUESTIONS & ANSWERS THAT I WILL ADD OVER TIME. ANY KEY CONCEPTS THAT I NEED TO FOCUS
ON MORE WILL BE USED IN THIS APP FOR MEMORIZATION. THIS APP WILL INCLUDE SIMPLE FEATURES
JUST FOR EASY NAVIGATION AND USE.


===========================================
FEATURES
===========================================
1. BUTTONS INCLUDE: 
        PREVIOUS CARD - GOES TO PREVIOUS CARD.
        NEXT CARD - GOES TO NEXT CARD.
        FLIP CARD - FLIPS TO REVEAL THE ANSWER TO THE QUESTION.
        MULTIPLE CHOICE SELECTION BUTTONS - IF THE USER CHOOSES CORRECTLY, THEY GET 1 POINT
        THAT WILL SHOW UP ON POINT COUNTER IN THE CORNER OF THE PAGE.

2. THE MAIN CARD DISPLAY: 
        QUESTIONS
        ANSWERS

3. CARD ANIMATIONS/FUNCTIONS:
        FLIPS WITH BUTTON AND REVEALS ANSWER
        WHEN USER CLICKS "FLIP" A JS FUNCTION WILL CHECK IF THE ANSWER IS RIGHT OR WRONG 
        COLOR CHANGES DEPENDING ON RIGHT OR WRONG ANSWERS
